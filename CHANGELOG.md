## 0.2.0

* Extract and list RAR archives with native UnRAR on Android, iOS, macOS, Linux, and Windows, including password-protected RAR4 and RAR5.
* Web still lists archives and reads entry bytes in Dart.

## 0.1.0

* List RAR4 and RAR5 archives, including password-protected data and encrypted headers.
* Extract an archive, or one entry, and return the absolute path of each written file.
* Test checksums, read a single entry as bytes, and report that RAR creation is not supported.
